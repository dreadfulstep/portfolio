# Personal Portfolio
A personal portfolio site to display my projects and past experience, alongside where to contact me.

Live site: https://dreadfulsteps.dev

<img width="1920" height="995" alt="Portfolio Preview" src="https://github.com/user-attachments/assets/40b260ae-3da6-43f4-b942-910f208eecb9" />

Created with Next.JS, inspired by UI found on designer platforms.

Setup:
```bash
pnpm install
```
Start:
```bash
pnpm build && pnpm start
```

To run it in development mode:
```bash
pnpm dev
```

Compatible with NPM and Yarn, built with pnpm.

https://lucide.dev/ waws used for the icons.
